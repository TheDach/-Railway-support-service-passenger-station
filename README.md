## 📋 О проекте

Система предназначена для ведения учета пассажиров, поездов, маршрутов и сотрудников. Функциональность включает создание новых расписаний для будущих маршрутов, управление билетами и автоматизированное ведение связанных данных.
<br>
### Технологии:
JavaEE, Apache Tomcat, HTML, CSS, JSP, servlets
<br>

## ⚙️ Функциональные возможности

### 🎫 Основные модули:
- **Учет пассажиров** - ведение базы данных пассажиров
- **Управление поездами** - информация о подвижном составе
- **Маршруты** - создание и управление железнодорожными маршрутами
- **Сотрудники** - учет рабочего персонала разделенные на бригады
- **Расписания** - планирование рейсов и отправлений

## 🔄 Процессы

### Создание рейса:
1. Создание маршрута
2. Назначение поезда и сотрудников
3. Указание даты/время отправления и прибытия

### Покупка билета:
1. Выбор расписания из списка
2. Ввод данных пассажира и автоматическое добавление нового в базу данных
3. Связывание билета с пассажиром
4. Учет проданых билетов

### Удаление данных:
- ❌ Удаление пассажира → удаление всех его билетов
- ❌ Удаление маршрута → удаление рейса
- ❌ Удаление рейса → удаление маршрута

## 🛠️ Технические особенности

- **Формы ввода** - валидация и сбор данных пользователя
- **Фильтрация** - поиск и отбор записей по критериям
- **Навигация** - возврат в главное меню, сброс фильтров, удаление, добавление и редактирование записи, фильтр
